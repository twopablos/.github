## 📂 Projects

### [ml-kaggle-sessions](https://github.com/twopablos/ml-kaggle-sessions)
Four end-to-end machine-learning notebooks from a course-internal Kaggle competition, in progression: from feature engineering and regression on Melbourne housing prices, to a boosting classifier written from scratch for imbalanced data, to CNNs for counting people in images.

`Python` · `scikit-learn` · `XGBoost` · `TensorFlow / Keras`

### [supermarket-price-scraper-db](https://github.com/twopablos/supermarket-price-scraper-db)
Web scrapers for three Spanish supermarkets (Carrefour, Mercadona, Eroski). They feed a price-comparison pipeline: ETL, a relational database designed from scratch, and SQL analysis of prices across stores.

`Python` · `BeautifulSoup` · `Selenium` · `SQL`
